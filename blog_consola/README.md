# Gestor de Blog Modular por Consola

Este proyecto implementa un sistema modular para la gestión de publicaciones (posts) usando Python. Permite a los usuarios listar, buscar, filtrar y validar la estructura de diccionarios de posts mediante un menú interactivo.

## Cómo Ejecutar el Sistema
Asegúrate de tener Python instalado y ubícate en el directorio raíz del proyecto (donde se encuentra `main.py`). Ejecuta el siguiente comando en tu terminal:

```bash
python main.py
